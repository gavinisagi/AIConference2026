> 评审人 Elon（Chief of Staff）· 收件人 Jobs（设计）/ 董事会 · 日期 2026-07-14
> 范围：**只审核，不改文件**。评审对象 = `design-spec.md` + `design/mockups/`（home-desktop、home-mobile、catalog-desktop）。
> 数据核对基于仓库 `data/catalog.json`（真实数据集）。

## A. 总体判断：能否公开给第一批用户

**结论：还不能，但很接近。** 桌面端首页与目录页在概念、信息层级、编辑气质上已达可上线水准；CTA 纪律与内容真实性处理到位。**两件事卡住公开发布：**

1. **移动端（产品的主设备）出现回归**——角色卡变成空壳、首屏内容有溢出/裁切；
2. **它仍是一份静态设计稿**——目录页的核心承诺"筛选出值得看的内容"在筛选器真正可用之前无法被验证（这正是第一周要验证的目标）。

修完下面的 P0/P1 清单，即可放给第一批用户。桌面端方向正确，不需要重做视觉。

## C. 每个问题的具体修改建议

**P0-1 移动端角色卡空壳**
桌面端角色卡带角标（128 / 84 / 56 / 32 内容）+ 一句"给你看什么"，移动端却退化为纯图标+名称。移动端是 spec §1.3 定义的主设备，恰恰在这里丢掉了"角色入口比普通分类更有用"的全部信息。
→ 给移动端 4 张角色卡补回：**数量角标 + 一行"给你看什么"**，与桌面 §4.1.3 对齐。

**P0-2 移动端首屏溢出**
`home-mobile.png` 中 H1、"1h 午间…"时间预算卡、观点卡正文均被右边缘裁掉。无论是截图视口问题还是真实横向滚动，移动优先产品不能带着首屏裁切上线。
→ 在 375 / 390 / 430px 下**消除横向滚动**；保证 spec §4.4 的首屏承诺：H1 + 主 CTA + 至少一个入口（角色或时间）完整可见。

**P1-3 统计数字与真实数据矛盾**
真实数据集 `data/catalog.json`：**941 场视频、约 409 小时**，来源分布 AI Engineer 853 / Figma Config 78 / Cursor Compile 10。稿面写的"已索引 320 场 · 302 小时"低估真实语料约 3 倍；"深度解读 48 场"在数据里**没有任何依据**（whyWatch/观点卡内容尚未生产，当前为 0）。连 Hero 的"300 小时"都低于真实 409 小时。
→ 用真实数据推导数字，或**明确标注为"目标/占位（需真实数据）"**。在真的有 N 场深度解读之前，不要显示"深度解读 48 场"。

**P1-4 静态稿 → 需要可用原型**
目录页筛选（大会/角色/主题/时长/状态 chip、排序下拉、结果计数）在稿中只是渲染，没有选中态联动、没有实时结果计数。spec §8.3 要求"筛选即时生效"。在筛选真正可用之前，第一周目标无法验证。
→ 打通 **筛选 → 实时结果计数 + 列表更新**（spec §8.3），把目录页从"设计稿"变成"可用原型"。注：此项属工程实现（Linus），非纯设计。

**P1-5 三大会平权错觉**
首页三个等大色点让用户以为三场大会内容量相当，实际 Cursor Compile 仅 10 条。偏向 Cursor 的角色/主题筛选会返回近乎空结果。
→ 保留三点式来源标识，但**为稀疏来源接好空状态**（spec §7.1 已设计，须真正接线）；可考虑在色点旁加一个克制的分场计数，避免暗示平权。

**P2 尾部**
- 页脚 `© 2024` → **2026**；页脚站名"COMPASS AI RESEARCH DIRECTORY"统一为产品名 **Compass**。
- "加载更多"按钮改用 `--accent`（墨蓝）而非纯黑，遵守 §3.7。

## D. 应该保留的设计（不要动）

- **H1「300 小时 AI 大会视频，不必全看」+ 编辑体副标题**：桌面端 5 秒内说清是什么，切中 Q1/Q2。
- **三轴导航（角色 / 时间预算 / 主题）作为首页中枢**：确实比扁平分类更有用，是产品的核心差异点（Q3）。
- **编辑式"为什么值得看" + 01–10 榜单序号**：信息层级清晰，像编辑精选而非视频堆砌（Q5）。
- **三态视觉分级**（推荐先看 暖金★+左强调条 / 已收录 / 解读中 脉冲点）：目录页视觉权重分级清楚（Q4）。
- **CTA 纪律**：唯一主 CTA「在 X 上关注更新」+ 次 CTA「加入候选名单」配诚实的"邮件筹备中"说明，全站无虚假社会证明。正确且诚实（Q6）。
- **内容诚实**：「示例讲者 / SAMPLE CONTENT · 非真实数据」标注、已移除真实具名嘉宾。**无虚构或不可信嘉宾信息（Q8 通过）**。
- **克制的编辑式视觉系统**（衬线标题 + 等宽元信息 + 发丝线）。按约束不重做。

## E. 只是偏好，不应优先实现

- **目录页大缩略图列**：spec 自己就说文本优先、缩略图可选。留不留是偏好，不该卡上线；若留，注意别喧宾夺主（当前右侧列偏大，边缘可接受）。
- **深色模式**：v1 明确非目标。
- **移动端底部常驻导航栏**：spec §9 待定，锦上添花，不卡上线。
- **衬线字体的具体选择、Hero 右侧留白 vs 放 Top1 小卡**：纯审美偏好。
- **时间预算区的深色反底块**：spec §10 已认定为可接受的区块对比，保留。
